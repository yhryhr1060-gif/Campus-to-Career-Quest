# Public placeholder artwork

The SVG files in this folder are original geometric placeholders created in code for this public
source export. They contain no embedded raster images, external resources, or third-party artwork.
The original five project illustrations are deliberately not included or licensed by this repository.
The original local game and its artwork have not been changed.

These placeholders preserve the scene dimensions and interaction anchors so the public code can build
and run without the private illustrations. They are functional substitutes, not reproductions of the
original art. This file does not grant a license for any omitted material.
